## Featured Projects

### [smartup-etl](https://github.com/Saydullayev-Oybek/smartup-etl)
> Production-grade ETL pipeline integrating SmartUp ERP API with PostgreSQL

- Extracts data from SmartUp REST API across 16+ entity pipelines (products, orders, payments, persons)
- Orchestrated via **Apache Airflow** with dimension → fact dependency structure
- Runs in **Docker** with idempotent upsert strategy and pre-load data validation
- Modular architecture: reusable core (HTTP client, transformer, loader, logger) + entity-specific pipelines
- Tested with **pytest**, linted with **ruff**

**Stack:** Python · pandas · PostgreSQL · Airflow · Docker · pytest
